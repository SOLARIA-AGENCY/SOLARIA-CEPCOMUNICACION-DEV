# ASSETS DE SLUGS - CEP FORMACIÓN
## 📋 Inventario Estratégico de URLs y Campañas

> **PRINCIPIO FUNDAMENTAL:** Los slugs de cursos son assets digitales valiosos que requieren gestión estratégica y tracking diferenciado según origen del tráfico.

---

## 🎯 **ESTRATEGIA DE RUTAS DOBLES**

### **ESTRUCTURA DE TRACKING DIFERENCIADO**

Cada curso activo tiene **2 URLs estratégicas**:

1. **🎯 RUTA DIRECTA (Facebook Ads)**
   - **Formato:** `cepcomunicacion.com/[curso-slug]`
   - **Propósito:** Landing específica para leads de Facebook
   - **Tracking:** Facebook Pixel + Eventos específicos de conversión
   - **Objetivo:** Máxima conversión sin fricción

2. **🌐 RUTA SEMÁNTICA (SEO/Orgánico)**
   - **Formato:** `cepcomunicacion.com/cursos/[curso-slug]`
   - **Propósito:** Estructura web semántica para tráfico orgánico
   - **Tracking:** Google Analytics + Eventos de navegación orgánica
   - **Objetivo:** SEO y arquitectura de información

### **1. IDENTIFICACIÓN DE OPORTUNIDAD**
- Análisis de demanda del curso
- Evaluación de competencia local
- Estudio de timing estacional

### **2. ACTIVACIÓN TÉCNICA**
```bash

# Activar ruta semántica (SEO)

# Configurar tracking diferenciado
echo "Pixel Facebook: [curso-slug]-direct"
echo "Analytics: [curso-slug]-organic"
```

### **3. CONFIGURACIÓN DE TRACKING**
- **Facebook Pixel:** Eventos específicos por curso
- **Google Analytics:** Goals separados por fuente
- **Tag Manager:** Triggers diferenciados

### **4. MONITOREO Y OPTIMIZACIÓN**
- Dashboard de conversión por canal
- A/B testing entre rutas
- Optimización continua según performance

## 📈 **MÉTRICAS CLAVE POR CANAL**

### **RUTAS DIRECTAS (Facebook)**
- **CTR:** Click-through rate desde ads
- **Conversion Rate:** % formularios completados
- **Cost per Lead:** Coste por inscripción
- **Quality Score:** Relevancia del anuncio

### **RUTAS SEMÁNTICAS (SEO/Orgánico)**
- **Organic Traffic:** Tráfico desde motores de búsqueda
- **Bounce Rate:** % rebote en página de curso
- **Time on Page:** Tiempo de permanencia
- **Pages per Session:** Navegación interna

## 🚀 **COMANDOS DE GESTIÓN**

### **SISTEMA IMPLEMENTADO** ✅

```bash
# 📊 GESTIÓN DE CAMPAÑAS
npm run campaigns:status    # Ver estado actual del sistema  
npm run campaigns:list      # Listar todas las campañas disponibles
npm run campaigns:analytics # Reporte de tracking configurado
npm run campaigns:help      # Ayuda y comandos disponibles

# 🔒 FLUJO DE SEGURIDAD PRE-DEPLOY
npm run pre-deploy         # Validación completa antes de despliegue
npm run safe-push          # Push automático tras validación exitosa
```

### **ROADMAP FUTURO** 🔄

```bash
# Activar nueva campaña (manual por seguridad)
npm run campaign:activate [slug] [sede]

# Desactivar campaña
npm run campaign:deactivate [slug]

# Verificar assets
npm run assets:audit

# Generar reporte de performance
npm run analytics:report [periodo]
```
